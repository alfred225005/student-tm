## Executive Summary
StudyFlow is a web-based Student Task Management System developed using the MERN stack. It is intended to help students organize assignments, due dates, priorities and completion status in one place. The frontend is built with React, while a Node.js and Express API validates requests and stores user and task records in MongoDB Atlas. The project includes account registration, login, and task CRUD operations. Results should be updated after actual testing and deployment.

## Introduction
Students may track assignments in separate notes or reminders, making deadlines and progress harder to manage. StudyFlow provides a central interface for recording and reviewing assignment tasks. It demonstrates full-stack web development, REST APIs, database modelling, authentication and responsive UI design.
